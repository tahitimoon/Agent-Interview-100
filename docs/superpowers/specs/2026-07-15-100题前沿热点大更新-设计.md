### 5.2 新增 4 道前沿题（#113–116）

#### `#113` Computer Use / Browser Use Agent（01-架构，高级）
- **简短回答**：什么是 Computer Use Agent（通过视觉/DOM 感知 GUI、规划点击等操作完成任务的 Agent）；与 API/Function Calling Agent 的本质区别（操作对象从「结构化 API」变为「图形界面」）
- **详细解析**：
  - 感知层：视觉模型截图识别 vs DOM/accessibility tree，各自优劣与混合方案
  - 决策层：如何把「点击登录按钮」映射到屏幕坐标/元素定位
  - 执行层：动作空间（click/type/scroll/drag）、操作原子化与状态机
  - 可靠性挑战：动态界面、加载等待、误点击、回溯与自我修复
  - 主流方案对比：Anthropic Computer Use、OpenAI Operator、Browser Use、Claude Computer Use
  - 架构图：感知 → 规划 → 执行 → 校验 循环
- **常见误区/面试追问**：
  - Computer Use 什么场景该用/不该用（成本、可靠性权衡）
  - 如何评估 GUI Agent（成功率、步数、OSWorld/WebArena 等基准）
  - 安全：如何防止误操作（确认机制、沙箱、权限隔离）
- **参考资料**：Anthropic Computer Use 博客、OSWorld/WebArena 论文、Browser Use 文档

#### `#114` Deep Research / Agentic Search（01-架构，中级）
- **简短回答**：Deep Research Agent 是什么（端到端「检索-阅读-再检索-综合」长报告生成）；与 Agentic RAG 的区别（Deep Research 是产品形态，Agentic RAG 是检索增强模式）
- **详细解析**：
  - 核心循环：query 规划 → 并行/串行检索 → 阅读+抽取 → 充分性判断 → 补充检索 → 综合报告
  - 关键技术：查询改写/分解、来源可信度评估、去重、引用管理、长报告合成
  - 与 Agentic RAG / 传统搜索的边界
  - 主流产品：OpenAI Deep Research、Perplexity Pro、Gemini Deep Research
  - 挑战：多轮调用成本、时效性、幻觉引用、来源偏见
- **常见误区/面试追问**：Deep Research vs RAG vs 搜索选型；质量评估；多轮检索成本控制
- **参考资料**：各产品技术博客、Agentic Search 相关论文

#### `#115` Agent 合规设计 / EU AI Act（09-安全，中级）
- **简短回答**：Agent 产品面临的合规要求（EU AI Act 高风险系统 2026.8.2 全面生效）；Agent 与传统软件合规的差异（自主决策、工具调用可审计性）
- **详细解析**：
  - EU AI Act 风险分级（禁止/高风险/有限/最小风险）
  - 高风险系统要求：透明度、人工监督、记录日志、数据治理、稳健性
  - Agent 特有合规点：自主决策可解释性、工具调用审计、记忆/数据隐私（GDPR 交叉）
  - 合规设计清单：透明度声明、HITL 卡点、全链路日志、PII 处理
  - 多法域对比：EU AI Act vs 中国《生成式 AI 服务管理暂行办法》vs 美国州级法规
- **常见误区/面试追问**：我的 Agent 算「高风险」吗（判定标准）；合规与迭代速度如何平衡；开源 Agent 责任归属
- **参考资料**：EU AI Act 全文与官方指南、各国生成式 AI 法规

#### `#116` 12-Factor Agents（10-生产，中级）
- **简短回答**：什么是 12-Factor Agents（humanlayer 提出的生产级 Agent 12 条原则）；为什么重要（生产化最佳实践共识，来源 24k star）
- **详细解析**：
  - 12 条原则逐条解读（native structured outputs、tools-as-first-class、compact context、small focused agents、prompt-as-code 等）
  - 每条原则解决的反模式
  - 与 12-Factor App 的呼应与差异
  - 落地：如何用这 12 条评审自己的 Agent 架构
- **常见误区/面试追问**：12 条优先级（必须全遵守吗）；与 LangGraph 等框架的关系；自研 vs 框架在原则遵循上的差异
- **参考资料**：`humanlayer/12-factor-agents`
