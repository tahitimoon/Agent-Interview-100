# 100 题前沿热点大更新 Implementation Plan

> **For agentic workers:** 本任务是 markdown 文章批量创作（非代码），TDD 质量门适配为「四段式 + 迁移完整性 + 交叉引用」质量门。执行用 Workflow 编排 subagent（每篇 fresh subagent 撰写 + 主控 review）。Steps 用 `- [ ]` 跟踪。

**Goal:** 保持 100 题总数不变，新增 4 道 2026.5-7 前沿题、置换（合并/废弃）4 道低价值题、升级 14 道题，同步更新 README。

**Architecture:** 5 批顺序执行（新增 → 合并接收 → 升级吸收 → 过时升级 → 废弃降级+README）。每批内多 subagent 并行撰写，主控做质量 review 后再进下一批。设计细节见 spec：`docs/superpowers/specs/2026-07-15-100题前沿热点大更新-设计.md`。

**Tech Stack:** 中文 Markdown 文章；四段式结构（简短回答 → 详细解析 → 常见误区/面试追问 → 参考资料）；编号废弃机制。
